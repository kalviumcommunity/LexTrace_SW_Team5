Internal Staff FAQ & Knowledge Base

Q1: How do I report a security vulnerability or leaked API key?
Immediately notify the InfoSec response team at security@lextrace.internal and revoke the affected key in the developer dashboard within 15 minutes.
Q2: Where can I find API rate limits for internal LLM microservices?
The default rate limit is 1,000 requests per minute per service account. High-throughput batch processing requires pre-approval from the AI Platform team.
Q3: What formats does the RAG document loader support?
The loader accepts PDF files, HTML web pages, Markdown documentation, and plain text files. Unsupported binary files are safely ignored.
